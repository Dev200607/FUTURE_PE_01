## 🧠 Prompt Logic & Framework

Every prompt follows this structure:

[Role] + [Business Context] + [Target Audience]
      + [Tone] + [Output Format] + [Goal]


### Each Element Explained

| Element        | What It Does                        | Example                          |
|----------------|-------------------------------------|----------------------------------|
| Role           | Tells AI who to behave like         | "You are a cafe copywriter..."   |
| Business Info  | Gives real business details         | Name, location, USPs, menu       |
| Target Audience| Defines who will read the copy      | Students, families, workers      |
| Tone           | Sets the feeling & personality      | Warm, bold, playful, peaceful    |
| Output Format  | Structures the exact response       | Headline + Intro + 5 USP points  |
| Goal           | Defines the action reader must take | "Visit the cafe today"           |
| Avoid List     | Tells AI what NOT to write          | No generic or formal language    |

---

### 📊 Prompt Quality — Simple Comparison

❌ Basic Prompt:
"Write copy for a cafe in Kharar"
→ Output: Generic & unusable

✅ Advanced Prompt (Used Here):
"You are a cafe copywriter. Client is
Nature's Coffee Cafe, Kharar. Rated 4.9/5.
100% vegetarian. Known for Biscoff Pancakes
& Flat White. Target: remote workers +
families. Tone: warm & peaceful.
Write: Headline + Intro + 5 USPs.
AVOID generic language.
GOAL: Make reader visit today."
→ Output: Specific, vivid, client-ready ✅
